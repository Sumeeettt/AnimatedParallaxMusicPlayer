🎵 Animated Parallax Music Player

An interactive and animated music player designed using Figma Make and developed with modern frontend technologies. The project focuses on creating an immersive music-listening experience through parallax effects, smooth transitions, and an engaging user interface.

✨ Features

- Animated parallax effects
- Modern and interactive music player interface
- Smooth UI transitions and animations
- Interactive playback controls
- Music track information
- Responsive design
- Visually engaging user experience

🛠️ Tech Stack

- TypeScript
- React
- Tailwind CSS
- Framer Motion
- Figma Make

🚀 Getting Started

 Prerequisites

- Node.js
- npm
- Git

 Installation

Clone the repository:

bash
git clone https://github.com/Sumeeettt/AnimatedParallaxMusicPlayer.git


Navigate to the project directory:

bash
cd AnimatedParallaxMusicPlayer


Install dependencies:

bash
npm install


Start the development server:

bash
npm run dev


Open the local development URL shown in your terminal.
